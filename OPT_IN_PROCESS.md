# NRM Opt-In Process

Last updated: September 11, 2026

NRM is a private personal relationship-management tool. Prospective users request access by visiting the [NRM access request form](https://forms.gle/peuiypGgPTh2YLHUA), providing their name and phone number, and checking a consent box agreeing to receive automated NRM text messages.

Submitted requests are reviewed individually by the account owner. A phone number is not authorized to use NRM unless the request has been manually reviewed and approved.

Users can reply **STOP** at any time to unsubscribe and stop receiving messages.

The form above is the sole method of requesting access; there is no automatic or self-service enrollment, and every request is manually reviewed and approved. NRM does not conduct cold outreach and does not use purchased contact lists.
