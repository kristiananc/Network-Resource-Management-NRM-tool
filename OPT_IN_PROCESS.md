# NRM Opt-In Process

Last updated: September 9, 2026

NRM is a private, invitation-only personal relationship-management tool. The account owner personally invites each prospective user, either in person or through a direct phone call or text message.

During that invitation, the account owner explains that by texting the NRM phone number, the user agrees to receive automated replies related to operating the tool, including workflow, review, correction, and confirmation messages. The invited user opts in by choosing to send a message to the NRM number after receiving this explanation.

Users can reply **STOP** at any time to unsubscribe and stop receiving messages.

No user is added without this direct, personal invitation. NRM has no public signup process, does not conduct cold outreach, and does not use purchased contact lists.
